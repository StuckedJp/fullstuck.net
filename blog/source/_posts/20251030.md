10/11～13の三連休で釧路町の難読地名ロードに行ってきました。
10/12 朝の 5 時、日の出前にホテルを出て最初の目的地に向かいます。最初の目的地は「又飯時」です。これは何とか読めそうです。
{% asset_img 01.jpeg 又飯時 (またいとき) %}

バス停がありますが、裏と表で名前が違います。
{% asset_img 02.jpeg 幸町バス停 %}
{% asset_img 03.jpeg 又飯時入口バス停 %}

道道 142 号を進んで行きます。
「地嵐別」。これも読みと漢字が一致してそうな感じです。
{% asset_img 04.jpeg 地嵐別 (ちあらしべつ) %}

「宿徳内」。これも常識の範囲内です。
{% asset_img 05.jpeg 宿徳内 (しゅくとくない) %}

「嬰寄別」。一気に難易度を上げてきました。
{% asset_img 06.jpeg 嬰寄別 (あっちょろべつ) %}

昆布森の看板は道道 142 号沿いに無かったので撮っていません。帰宅後調べてみたら釧路町昆布森支所にあるようです。
「伏古」。これは難読って感じではないですね。
{% asset_img 07.jpeg 伏古 (ふしこ) %}

「幌内」。この字で「ホロナイ」と読ませる場所は、北海道にはそこかしこにありますが、ここは「ポロナイ」でちょっと変化球をつけてます。
{% asset_img 08.jpeg 幌内 (ぽろない) %}

「来止臥」。こちらも変化球が付いています。
{% asset_img 09.jpeg 来止臥 (きとうし) %}

「十町瀬」。素直な読みです。
{% asset_img 10.jpeg 十町瀬 (とまちせ) %}

十町瀬の集落は廃村になったようですが、通信施設の名前に残っています。
{% asset_img 11.jpeg 十町瀬中継所 %}
{% asset_img 12.jpeg 巨大なアンテナ %}

交通安全のお地蔵さんもいます。
{% asset_img 13.jpeg お地蔵さん %}
{% asset_img 14.jpeg 交通安全 %}

「浦雲泊」。ここから難易度が上がってきます。
{% asset_img 15.jpeg 浦雲泊 (ぽんとまり) %}

「跡永賀」。読みが判れば納得な当て字。
{% asset_img 16.jpeg 跡永賀 (あとえか) %}

「冬窓床」。地名の漢字は後から当てるのが普通ですが、これほど常識はずれな当て字は無いでしょう。
{% asset_img 17.jpeg 冬窓床 (ぶいま) %}

「初無敵」。これも読みが判れば納得な当て字。
{% asset_img 18.jpeg 初無敵 (そんてき) %}

「入境学」。「ニコ」になぜ「入境」を当てた ?
{% asset_img 19.jpeg 入境学 (にこまない) %}

「賤夫向」。これも難しい。
{% asset_img 20.jpeg 賤夫向 (せきねっぷ) %}

賤夫向にはトイレ付きの駐車場があります。駐車場からは太平洋が一望でき、なかなかのロケーションです。天気が良ければさぞ気持ちいいことでしょう。
{% asset_img 21.jpeg 賤夫向から太平洋を望む %}
{% asset_img 22.jpeg 賤夫向から望む山々 %}
{% asset_img 23.jpeg 賤夫向から望む道路 %}

「分遣瀬」。何を食ったら「チャラ」に「遣」を当てようと思うのか ? 看板は「分遺瀬」となっていますが「分遣瀬」が正しいようです。
{% asset_img 24.jpeg 分遣瀬 (わかちゃらせ) %}

「円山」。この看板はなぜか緑です。難読地名ではないから ?
{% asset_img 25.jpeg 円山 (まるやま) %}

「老者舞」。「オシャ」まあわかるが「マップ」に「舞」を当てた理由がわからない。
{% asset_img 26.jpeg 老者舞 (おしゃまっぷ) %}

ここからは道道 142 号をいったん外れ、尻羽岬方面へ進んでいきます。
「知方学」。「チポ」という響きがかわいい。
{% asset_img 27.jpeg 知方学 (ちぽまない) %}

デマンドバスの待合室があります。前日までに予約が必要とのこと。
{% asset_img 28.jpeg 知方学停留所の時刻表 %}

ここからはダートになります。
「去来牛」。これは常識的な当て字です。
{% asset_img 29.jpeg 去来牛 (さるきうし) %}

「尻羽岬」は厚岸湾を構成する岬です。「シリ」ではなく「シレ」なところが微妙に難読です。駐車場から徒歩 30 分くらいで行けるようですが、風が強いのと天気も悪くいつ大雨にやられるかわからないので、今回は断念しました。駐車場やここに向かう道でも北海道らしいクマザサの丘陵地を堪能できます。

{% asset_img 34.jpeg 尻羽岬に通じる道からの風景 %}

{% asset_img 37.jpeg 尻羽岬に通じる道からの風景 %}

老者舞まで戻って道道 142 号を厚岸方面へ進んでいきます。
「古番屋」。ほぼ和名ですね。
{% asset_img 38.jpeg 古番屋 (ふるばんや) %}

「仙鳳趾」。こちらも常識的な当て字です。
{% asset_img 39.jpeg 仙鳳趾 (せんほうし) %}

「重蘭窮」。仙鳳趾の公園の隣にある公民館っぽいところにありました。
{% asset_img 40.jpeg 重蘭窮 (ちぷらんけうし) %}

難読地名めぐりは終わりましたが、ひとつ気になる地名があるのでそこに行ってきます。
「オタクパウシ」。ちゃんと緑の看板が立っています。看板が立っているのはオタクパウシの集落のかなり手前です。オタクパウシの中心には牧場しかないようなので、ここで折り返しました。
{% asset_img 41.jpeg オタクパウシ %}
{% asset_img 42.jpeg さまざまなオタク %}
{% asset_img 43.jpeg さまざまなオタク %}
{% asset_img 44.jpeg うし %}

トイレに行きたかったので尾幌駅に行ってみましたが、車掌車転用の駅舎でした。ただ駅前にコンビニがありましたのでそちらで用を足しました。駅前には新鮮な野グソがありました。コンビニまで我慢できなかったのでしょうか…
{% asset_img 45.jpeg 尾幌駅 %}
{% asset_img 46.jpeg 尾幌駅 %}

余裕のありすぎる計画を立てていたので、4 時間ほど時間が余りました。とりあえず釧路に戻ることにしました。尾幌駅を出てすぐ発見したのが「ハト」の警戒標識。「あっ !  ハトだ !!」って声が出ちゃいましたね。
{% asset_img 47.jpeg 「ハ」「ト」の警戒標識 %}

釧路のマックで 2 時間ほどダラダラして、地図を見てて思い立ったので東釧路駅に向かいます。なかなか立派な駅です。
{% asset_img 48.jpeg 東釧路駅 %}

だだっ広い待合室に 8 人分のベンチがあります。
{% asset_img 49.jpeg 東釧路駅の待合室 %}

国鉄おなじみのどどめ色の看板です。
{% asset_img 50.jpeg 東釧路駅の看板 %}

釧網本線の 0 キロポストです。根室本線の 313k800 は滝川からの距離です。今はもうつながっていません。
{% asset_img 51.jpeg 釧網本線の 0 キロポスト %}

駅前にはコープさっぽろ貝塚店があります。コープのくせにダイソーやら無印やら GEO やらが入ってます。広大な駐車場がありますし、本数も少ないので鉄道で訪れる人はまずいないでしょう。
{% asset_img 52.jpeg コープさっぽろの駐車場から %}

というわけで釧路町の難読地名巡りを終え、その日の夜は寿司を食べ、翌日帰りました。
{% asset_img 53.jpeg 釧路の夜景 %}
